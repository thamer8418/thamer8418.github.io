# ثامر الحربي — موقع التصوير الفوتوغرافي

موقع ثابت بالعربية، من اليمين لليسار. مبني بـ HTML وCSS وJavaScript فقط، بدون أي مكتبات خارجية. يعمل على GitHub Pages كما هو.

## صفحات الموقع

| الصفحة | الملف | من يراها |
|---|---|---|
| الرئيسية (الأعمال) | `index.html` | الجميع. تعرض مختارات من أعمالك، وبطاقات الأقسام. |
| القسم | `thamer8418.github.io/weddings` | من يملك كلمة مرور هذا القسم فقط. |
| للحجز والتواصل | `contact.html` | الجميع. |
| لوحة التحكم | `admin/` | أنت فقط، عن طريق رمز وصول GitHub. |

**فصل الأقسام:**
- لكل قسم صفحة مستقلة وكلمة مرور خاصة به.
- كلمة مرور الزواجات تفتح الزواجات فقط، ولا تفتح المعارض أو غيرها.
- صفحة القسم لا تحتوي على أي رابط للأقسام الأخرى.
- أرسل للعميل رابط قسمه وكلمة مروره فقط. الروابط مختصرة:
  - thamer8418.github.io/weddings
  - thamer8418.github.io/events
  - thamer8418.github.io/portraits
  - thamer8418.github.io/real-estate
- عند إضافة قسم جديد من اللوحة يحصل تلقائيًا على رابط مختصر بنفس اسم الرابط الذي تختاره.

```
thamer-portfolio/
├── index.html · section.html · contact.html · 404.html
├── data/site.json        ← كل المحتوى: الصور، النصوص، الأقسام، كلمات المرور (تعدّله لوحة التحكم)
├── admin/                ← لوحة التحكم
├── assets/css/style.css  ← التصميم والألوان
├── assets/js/            ← برمجة الموقع (لا تحتاج تعديلها)
├── assets/fonts/         ← خط ثمانية (Thmanyah Serif Display)
├── assets/logo/          ← شعارك
└── assets/images/<قسم>/   ← الصور بأحجام الويب
```

## ١. النشر على GitHub Pages (مرة واحدة)

1. أنشئ حسابًا على github.com إن لم يكن لديك حساب.
2. الموقع منشور في المستودع `thamer8418/thamer8418.github.io`. تسمية المستودع بهذا الشكل تجعل عنوان الموقع قصيرًا: **https://thamer8418.github.io**. المستودع **Public** لأن الحساب المجاني لا يدعم Pages إلا مع المستودعات العامة.
3. ارفع **محتويات** هذا المجلد بحيث يكون `index.html` في أعلى المستودع. يمكنك السحب والإفلات في صفحة «Add file ← Upload files».
4. افتح **Settings ← Pages**، واختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
5. بعد دقيقة أو دقيقتين يظهر أي تحديث على: `https://thamer8418.github.io`
6. اختياري: لاستخدام نطاق خاص مثل `thameralharbi.com`، أضفه في Settings ← Pages، واتبع إعدادات DNS التي يعرضها GitHub، ثم فعّل **Enforce HTTPS**.

## ٢. لوحة التحكم: إضافة الصور وحذفها وتعديل النصوص

افتح `https://thamer8418.github.io/admin/`، واكتب: اسم المستخدم `thamer8418`، والمستودع `thamer8418.github.io`، والفرع `main`.

**أول مرة فقط: احصل على رمز وصول (Token)**
1. افتح github.com/settings/personal-access-tokens/new
2. اكتب اسمًا مثل «لوحة الموقع» واختر مدة الصلاحية.
3. في **Repository access** اختر **Only select repositories**، ثم المستودع `thamer8418.github.io` فقط.
4. في **Permissions ← Repository permissions** اجعل **Contents** على **Read and write**.
5. اضغط **Generate token**، وانسخ الرمز والصقه في اللوحة مع اسم المستخدم واسم المستودع.

الرمز يُحفظ في متصفحك فقط. لا تشاركه مع أحد. وإن فقدت جهازك، احذف الرمز من نفس صفحة GitHub.

**ما تستطيع فعله من اللوحة:**

| التبويب | ما فيه |
|---|---|
| **الصور** | إضافة صور (اختيارها أو سحبها) إلى أي قسم، وحذفها، وكتابة العنوان والوصف، ونقل صورة لقسم آخر، وترتيب الصور بالسحب أو بالأسهم، واختيار ما يظهر في **مختارات الرئيسية**، وتمييز صورة بـ**عرض كبير**. |
| **الأقسام وكلمات المرور** | تغيير اسم القسم ووصفه وصورة غلافه، وتعيين كلمة مرور جديدة، ونسخ رابط القسم لإرساله للعميل، وترتيب الأقسام، وإضافة قسم جديد (مثل التصوير الجوي) أو حذف قسم فارغ. |
| **النصوص والتواصل** | كل نصوص الموقع، والبريد، وواتساب، وإنستقرام، والمدينة. |
| **الإعدادات** | قفل الموقع كاملًا بكلمة مرور، ووضع الألوان عند أول زيارة. |

بعد أي تعديل اضغط **«حفظ ونشر»**. تُرفع كل التعديلات دفعة واحدة، وتظهر على الموقع خلال دقيقة تقريبًا.

**ملاحظات:**
- الصور تُصغَّر تلقائيًا داخل المتصفح إلى أحجام الويب (800 و1600 و2400 بكسل). ملفك الأصلي على جهازك لا يتغيّر.
- صدّر الصور من Lightroom بصيغة **JPEG** وبأعلى جودة. صيغة HEIC لا تُقرأ في Chrome.
- كلمة المرور لا تُحفظ نصًا، بل تُحفظ «بصمتها» (SHA-256)، لذلك لا يمكن عرضها لاحقًا. احتفظ بكلمات المرور عندك.
- زر «تجربة اللوحة بدون GitHub» يسمح بالتجربة دون حفظ أي شيء على الموقع.

## ٣. ⚠ حدود الحماية بكلمة المرور (مهم)

GitHub Pages استضافة ثابتة لا تستطيع التحقق من كلمات المرور على الخادم. لذلك كلمات المرور هنا **حماية ردع**، أي أنها تمنع الزائر العادي، و**ليست أمانًا حقيقيًا**:
- كل ملفات المستودع عامة. من يعرف رابط صورة مباشرًا يستطيع فتحها، ومن يملك خبرة تقنية يستطيع قراءة `data/site.json`.
- المستودع العام يمكن تصفّح ملفاته على GitHub.

هذه الحماية مناسبة لفصل الأقسام عن الزوار العاديين. أما معارض العملاء الخاصة التي يجب ألا يراها أحد، فتحتاج حماية حقيقية.

### الحماية الحقيقية: Cloudflare Access (مجاني حتى 50 مستخدمًا)
1. انقل نطاقك الخاص إلى Cloudflare (الخطة المجانية) ووجّهه إلى GitHub Pages.
2. من **Cloudflare Zero Trust ← Access ← Applications** أضف تطبيقًا من نوع *Self-hosted* لنطاقك.
3. أضف سياسة دخول، مثل قائمة بريد إلكتروني محددة لكل عميل. يصل للزائر رمز دخول على بريده.

بعدها يُفحص كل طلب، بما فيه روابط الصور المباشرة، على خوادم Cloudflare قبل إرسال أي شيء.

## ٤. تغيير الشعار
- الشعار مستخدم كقالب شفاف (`assets/logo/logo-600.png`)، ولذلك يتلوّن تلقائيًا: فاتح في الوضع الداكن، وداكن في الوضع الفاتح.
- لاستبداله: احفظ شعارًا جديدًا بصيغة **PNG بخلفية شفافة** وبأي لون واحد، وبارتفاع نحو 600 بكسل، بنفس الاسم.
- إن اختلفت أبعاد الشعار الجديد، عدّل `aspect-ratio: 989 / 1076` في `.logo-mark` داخل `assets/css/style.css` إلى العرض / الارتفاع الجديد.
- ملفك الأصلي محفوظ كما هو في `assets/logo/logo-original.webp`.

## ٥. الألوان والخط
- وضع الألوان عند أول زيارة يُختار من **الإعدادات** في اللوحة. بعدها يُحفظ اختيار الزائر.
- ألوان الوضعين في أعلى `assets/css/style.css`: قسم `:root` للفاتح العاجي، وقسم `[data-theme="dark"]` للداكن.
- الخط هو **Thmanyah Serif Display**. لتغييره ضع ملفات `.woff2` الجديدة في `assets/fonts/` وعدّل أسطر `@font-face` في أعلى ملف التصميم.

## ٦. تجربة الموقع على جهازك
```bash
cd thamer-portfolio
python3 -m http.server 8000
```
ثم افتح http://localhost:8000. فتح `index.html` مباشرة بالنقر عليه لن يعمل، لأن الموقع يقرأ بياناته من `data/site.json`.

## ٧. جاهز للتوسّع لاحقًا
- **قسم جديد:** يُضاف من اللوحة، ويحصل تلقائيًا على صفحته وكلمة مروره وبطاقته في الرئيسية.
- **صفحة جديدة** (عنّي، الحجز…): انسخ `contact.html` وأبقِ الترويسة والتذييل. الوضع الليلي والانتقالات تعمل تلقائيًا.
- **نموذج حجز:** يمكن ربطه لاحقًا بخدمة نماذج مثل Formspree، لأنه لا يوجد خادم. وزر واتساب يرسل رسالة جاهزة.
